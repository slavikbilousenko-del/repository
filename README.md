«Динозаврик» на Python (tkinter) — аркадный раннер без сторонних библиотек.
Суть игры

Управляй динозавром, уворачивайся от препятствий и набирай очки. Игра плавно ускоряется со временем и за каждое пройденное препятствие (до лимита 18.0 единиц скорости).
Управление

    Пробел (Space) — прыжок; при проигрыше — быстрый рестарт.

    Стрелка вниз (↓) — приседание (уменьшает высоту динозавра, пока клавиша зажата).

Препятствия и HUD

    Кактусы — появляются с самого старта, нужно перепрыгивать.

    Птицы — подключаются с 3 очков на двух высотах: верхних можно пробежать пригнувшись, нижних — перепрыгнуть.

    Интерфейс — вверху выводятся текущий Счёт и множитель Скорости (1.0x и выше).
